# OneUI 0.5.9 Release Plan

## 发布目标

将 OneUI 当前仓库状态以补丁版本 `0.5.9` 发布到 npm，覆盖 package boundary 治理、plugin consumer chunk slimming、release traceability 补齐以及治理元数据收口后的最新状态。

## 发布范围

1. [`package.json`](/opt/Oneflow/flowlab/项目/oneui/code/develop/package.json) 版本提升到 `0.5.9`
2. [`src/utils/icon.ts`](/opt/Oneflow/flowlab/项目/oneui/code/develop/src/utils/icon.ts) 与 [`src/utils/iconRegistry.ts`](/opt/Oneflow/flowlab/项目/oneui/code/develop/src/utils/iconRegistry.ts) 完成字符串图标注册表拆分，避免 plugin consumer 首包携带完整注册表
3. [`docs/plans/2026-03-21-package-boundary-governance-verification.md`](/opt/Oneflow/flowlab/项目/oneui/code/develop/docs/plans/2026-03-21-package-boundary-governance-verification.md) 与 release 三件套形成连续回溯链
4. [`docs/CHANGELOG-v0.5.0.md`](/opt/Oneflow/flowlab/项目/oneui/code/develop/docs/CHANGELOG-v0.5.0.md) 对外说明同步

## 发布前条件

1. `pnpm lint`
2. `pnpm lint:style`
3. `pnpm type-check`
4. `pnpm test`
5. `pnpm build`
6. `npm publish --dry-run --registry=https://registry.npmjs.org`
7. `npm pack`
8. tarball 外部 consumer smoke 覆盖 `Vite 5.4.21` 与 `Vite 8.0.1`

## 发布结论

本次发布为补丁版本，不引入新的 breaking change，对外目标是让 npm 包状态与当前仓库的 package boundary、页面能力和治理状态保持一致。
