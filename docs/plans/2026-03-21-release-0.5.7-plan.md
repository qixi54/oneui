# OneUI 0.5.7 Release 计划

## Part 1: 执行摘要

`0.5.6` 之后，仓库继续吸收了 warning zero-out、skill-based review 发现项收口，以及若干对外包质量相关的小范围修正。当前目标是将本地已验证的状态正式发版为 `@oneflowui/ui@0.5.7`，让 npm 包与当前仓库状态一致。

## Part 2: 需求分析

当前 npm 主站版本仍为 `0.5.6`，但本地代码已继续前进：

1. warning 已清零，`pnpm lint` 达到 `0 warning`
2. `ExcelExport.vue` 去除了 `@ts-ignore`
3. `Dashboard/index.vue` 与 `src/dev/App.vue` 中的弱类型使用进一步收口
4. 验证文档补强，避免 `/tmp` 产物成为唯一证据载体

因此需要执行一次补丁版本发布，而不是继续停留在本地未发布状态。

## Part 3: 详细方案

1. 将版本号从 `0.5.6` 升到 `0.5.7`
2. 更新 changelog，记录 `0.5.7` 的补丁范围
3. 按 release checklist 执行：
   - `pnpm type-check`
   - `pnpm test`
   - `pnpm build`
   - `pnpm lint`
   - `pnpm lint:style`
   - `npm publish --dry-run --registry=https://registry.npmjs.org`
   - `npm pack`
   - tarball 外部 consumer build smoke（Vite `5.4.x` + 当前最新稳定 Vite）
4. 发布到 npm 主站
5. 写入 release proof，并完成 FlowAPI closeout

## Part 4: 实现路线图

| 阶段 | 里程碑 | 说明 |
|------|--------|------|
| Phase 1 | 版本与文档更新 | bump version + changelog |
| Phase 2 | 仓库内验证 | lint/type-check/test/build/style |
| Phase 3 | 发布验证 | dry-run + pack + consumer smoke |
| Phase 4 | npm 发布与留痕 | publish + release proof + plan complete |

## Part 6: 风险评估

| 风险 | 等级 | 说明 | 应对 |
|------|------|------|------|
| 本地通过但 tarball 消费失败 | Medium | 库模式与消费宿主可能偏差 | 强制执行外部 consumer smoke |
| npm registry 配置错配 | Medium | 镜像与 token 站点可能不一致 | 显式使用 npmjs 主站 |
| 发布版本号与 changelog 不一致 | Low | 文档/元数据不同步 | 同轮更新 package.json 与 changelog |

## Part 7: 验收标准

1. 版本号已更新为 `0.5.7`
   ```bash
   bash -lc 'cd /opt/Oneflow/flowlab/项目/oneui/code/develop && node -p "require(\"./package.json\").version"'
   ```
2. 仓库内验证通过
   ```bash
   bash -lc 'cd /opt/Oneflow/flowlab/项目/oneui/code/develop && pnpm lint && pnpm lint:style && pnpm type-check && pnpm test && pnpm build'
   ```
3. 发包前检查通过
   ```bash
   bash -lc 'cd /opt/Oneflow/flowlab/项目/oneui/code/develop && npm publish --dry-run --registry=https://registry.npmjs.org && npm pack'
   ```
4. tarball 外部 consumer smoke 通过
   ```bash
   bash -lc 'test -f /tmp/oneui-release-0.5.7/vite5/build.ok && test -f /tmp/oneui-release-0.5.7/vite-latest/build.ok'
   ```
5. npm 主站版本可读为 `0.5.7`
   ```bash
   bash -lc 'npm view @oneflowui/ui version --registry=https://registry.npmjs.org'
   ```

## Part 8: 回滚方案

1. 发布前任何一步失败，停止发布，不修改线上 npm 状态。
2. 若 dry-run/pack/consumer smoke 失败，先修问题再重新验证，不做带病发版。

## Part 9: 架构决策记录

1. 本轮按补丁版本发布，选择 `0.5.7`，不升级到 `0.6.0`
2. 本轮重点是“让 npm 包追平当前仓库状态”，不是新增大功能版本
