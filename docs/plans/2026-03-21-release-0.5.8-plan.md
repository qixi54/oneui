# OneUI 0.5.8 Release Plan

## 发布目标

将 OneUI Database UX 对齐能力以补丁版本 `0.5.8` 发布到 npm，并保证 release 证据可回溯到实现、验证与治理计划。

## 发布范围

1. [`package.json`](/opt/Oneflow/flowlab/项目/oneui/code/develop/package.json) 版本提升到 `0.5.8`
2. [`src/components/database/DatabaseView.vue`](/opt/Oneflow/flowlab/项目/oneui/code/develop/src/components/database/DatabaseView.vue) 引入 `detailPresentation` 与 `density`
3. [`src/components/table/DataTable.vue`](/opt/Oneflow/flowlab/项目/oneui/code/develop/src/components/table/DataTable.vue) 与 [`src/composables/useColumnResize.ts`](/opt/Oneflow/flowlab/项目/oneui/code/develop/src/composables/useColumnResize.ts) 完成内容感知列宽和密度收敛
4. [`README.md`](/opt/Oneflow/flowlab/项目/oneui/code/develop/README.md) 与 [`docs/CHANGELOG-v0.5.0.md`](/opt/Oneflow/flowlab/项目/oneui/code/develop/docs/CHANGELOG-v0.5.0.md) 对外说明同步

## 发布前条件

1. `pnpm lint`
2. `pnpm type-check`
3. `pnpm test -- src/tests/database-view.integration.spec.ts src/tests/table-detail.integration.spec.ts`
4. `pnpm build`
5. `npm publish --dry-run --registry=https://registry.npmjs.org`
6. `npm pack`
7. tarball 外部 consumer smoke 覆盖 `Vite 5.4.21` 与 `Vite 8.0.1`

## 发布结论

本次发布为补丁版本，不改变根入口与 plugin 入口的对外 API 契约，仅将 OneUI 数据页面默认交互形态对齐到更接近目标产品体验的状态。
